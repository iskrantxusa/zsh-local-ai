# zsh-local-ai

Переносимая локальная подсказка команд для Zsh на базе
[`zsh-ai`](https://github.com/matheusml/zsh-ai) и Ollama.

## Установка

Скопируйте весь каталог в любое место и выполните:

```sh
./install.sh
exec zsh
```

Установщик:

- создаёт стабильную ссылку `~/.config/zsh-local-ai` на текущий каталог;
- подключает конфигурацию к `~/.zshrc.local`;
- устанавливает и запускает пользовательскую службу Ollama;
- скачивает модель из `settings.env`.

Требования: `zsh`, `curl`, `perl`, `jq`, `ollama`, `systemctl` и пользовательская
сессия systemd. Сам плагин уже находится в `vendor/zsh-ai`.

## Использование

Введите описание с префиксом `# ` и нажмите Enter:

```text
# найти десять самых больших файлов
```

Описание будет заменено командой без её автоматического выполнения. Проверьте
команду и нажмите Enter ещё раз, чтобы выполнить.

## Настройка

Модель и адрес Ollama находятся в `settings.env`:

```sh
ZSH_LOCAL_AI_MODEL='qwen2.5-coder:3b'
ZSH_LOCAL_AI_URL='http://127.0.0.1:11434'
```

После смены модели снова запустите `./install.sh`, чтобы скачать её. Если каталог
перемещён, также повторно запустите установщик — он обновит символические ссылки.

Служба слушает только loopback-адрес `127.0.0.1:11434`. Прокси автоматически
обходится только для `localhost`, `127.0.0.1` и `::1`.

## Версия плагина

Плагин включён в репозиторий обычными файлами, поэтому клон остаётся
самодостаточным и не требует Git submodules. Источник и зафиксированная версия
указаны в `vendor/UPSTREAM.md`.
